Todo mundo procura um editor style pra desenvolver seu trabalho de forma otimizada, mas editor de código é igual arquitetura de sistema de informação, cada um teu seu preferido. 🙂

Primeiramente, devemos ter claro que o editor de código não é algo primordial para um bom desenvolvimento de software em [**PHP**](http://www.php.net), já no [Java](http://www.java.com) é algo primordial. Há outros fatores que são bem mais importantes para maior qualidade e produtividade, como a escolha de bons [frameworks](http://pt.wikipedia.org/wiki/Framework), [geradores](http://pt.wikipedia.org/wiki/Gerador_de_C%C3%B3digo) [de cógido](http://pt.wikipedia.org/wiki/Gerador_de_C%C3%B3digo) e de [artefatos](http://www.lbd.dcc.ufmg.br:8080/colecoes/sbes/2001/020.pdf), padrões, entre outros aspectos. Se hoje o editor é algo primordial em seu desenvolvimento PHP, repense seu processo de desenvolvimento, pois, ele não está atualizado, ou tem aspectos de desenvolvimento atrasados.

Acho que alguns aspectos são bem interessantes pra um editor PHP:

- Project Manager;
- Auto-completar de tag [HTML](http://pt.wikipedia.org/wiki/HTML), de preferência fechando as tags automaticamente, mas não sendo intrusivo;
- Code Assist sobre as linguagens [JavaScript](http://pt.wikipedia.org/wiki/JavaScript), HTML e [CSS](http://pt.wikipedia.org/wiki/CSS);
- PHP Syntax Check, Code Completion e Functions Hint;
- Possibilidades de customização de templates;
- Navegação entre os códigos PHP(Classes, métodos, includes,...);
- PHP Debugger;
- Integração com controles de versão, principalmente o [SVN](http://pt.wikipedia.org/wiki/Subversion);

Difícilmente teremos editores livres com todas essas características, particularmente, ainda não achei. É bem mais difícil se desenvolver um editor realmente bom em PHP, por ser de [tipagem dinâmica](http://en.wikipedia.org/wiki/Type_system#Dynamic_typing) e não [type-safe](http://en.wikipedia.org/wiki/Type_safety) por padrão. Por isso é admirável o Zend Studio, que na minha opinião, é o melhor editor de código independente de linguagem.

No site [PHP Editors](http://www.php-editors.com/review/) temos uma lista dos principais editores PHP e uma descrição breve sobre suas funcionalidades.

Abaixo destaco alguns:

**[Tulip](http://tulip.solis.coop.br/us/index.php)**\
Editor PHP desenvolvido em [PHP-GTK](http://www.php-gtk.com.br/) pelo [Pablo Dall'Oglio](http://pablo.blog.br/). Muito bom, muito leve e independente de plataforma. Não sei se ele será atualizado, já que a última versão, que tive acesso, foi lançada em 2005.



[**Quanta Plus**](http://quanta.kdewebdev.org/)\
Um dos meus atuais editores PHP. Acho ele razoável, no meu [Gnome](http://www.gnome.org/) ele é um pouco instável, mas no geral o achei bem melhor que os plugins do [Eclipse](http://www.eclipse.org/).



**[PDT Project](http://www.eclipse.org/pdt/)**\
O Projeto PHP Development Tolls promete, é apoiado por diversas empresas, inclusive a [Zend](http://www.zend.com). A versão 1.0 está prevista pra este mês. Utilizei por algum tempo, e não gostei muito. Na verdade, não gostei de desenvolver PHP no Eclipse, em todos os plugins que utilizei([PHP Eclipse](http://www.phpeclipse.de/tiki-view_articles.php), [Xored Web Studio](http://www.xored.com/products.php)). Em geral, vão requerer memória considerável, e são bem grandes na instalação devido a reutilizarem outros plugins do própio Eclipse.

[Zend Studio](http://www.zend.com/store/software/zend_studio/lp?engine=google&cmpg=zend_studio&k_id=editor_php)\
É o melhor, mas é pago.



[Komodo](http://www.activestate.com/products/komodo_edit/)\
Me parece ser interessante, prometo que vou testá-lo logo. É o preferido do [ASF](http://antoniofonseca.wordpress.com/).



[Dreamweaver](http://www.adobe.com/br/products/dreamweaver/)\
É bonito, vicia, é pago, acostuma mal e tá ficando mais pesado. Portanto quem quer usar mesmo assim tem que saber o que está fazendo e ter cuidado pra não gerar código excessivo e fora dos padrões, o que não deixaria feliz o meu amigo [Karlisson](http://nerdson.com/).

Outros editores for Windows interessantes são:\
[PHP Expert Editor](http://www.ankord.com/phpxedit.html), [TSWebEditor](http://tswebeditor.net.tc/), [Maguma Studio](http://www.maguma.com/) e o [PHP Editor](http://paginas.terra.com.br/informatica/php_editor/).

Não posso deixar de citar também o tradicional [VIM](http://www.vim.org/), o qual foi representado por um bom tutorial ministrado pelo Luiz Sanches do [grupo PHP Pai d'Égua](http://sig.ufpa.br/phppaidegua/) no [V FPSL](http://www.ausla.org/).

Além disso não esqueça dos plugins [Firebug](https://addons.mozilla.org/en-US/firefox/addon/1843) e [WebDeveloper](https://addons.mozilla.org/en-US/firefox/addon/60) do [Firefox](http://br.mozdev.org/).

Pra designer a coisa é um pouco diferente, mas como essa não é minha área, alguém pode escrever outro post pra isso. 🙂

Enfim, fique a vontade e escolha o seu editor preferido.
